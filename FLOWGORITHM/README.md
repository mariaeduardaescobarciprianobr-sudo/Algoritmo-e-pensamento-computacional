# Instruções para uso
------------
O código irá solicitar que você escolha uma das opções de operação, a que o usuário desejar. Depois de selecionada, ele irá pedir os valores, podendo ser um ou dois para que consiga realizar o cálculo desejado, depois disso ele mostrará o resultado. 

------------
# Resumo do meu código
------------
###Variáveis
O código em flowgorithm foi criado no programa próprio a ele, realizado por meio de um fluxograma, onde cada operação tinha entre 2 ou 3 variáveis, com padrão de A,B e C.

### A
O usuário digita o primeiro número.

### B 
Para alguns o B já era usado para realizar a conta somente com um número, como raiz quadrada. Em outros ele era usado para que usuário colocasse o segundo número.

### C 
O C, em todos no qual aparece, era a realização da conta utilizando os números A e B, determinados pelo usuário.

### Saída de código
output é a saída do código, ou seja, a resposta da operação.
